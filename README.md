# MIS Flutter Labs

A collection of Flutter applications developed as laboratory exercises for the **Mobile Information Systems (MIS)** course.

The repository contains two independent Flutter projects demonstrating mobile application development, API integration, navigation, data handling, and user interface design.

## Projects

### 📅 Exam Schedule App

A Flutter application for managing and displaying exam schedules.

**Features:**
- Displays upcoming and past exams
- Shows detailed information for each exam
- Tracks the remaining time until an exam
- Provides clear visual distinction between upcoming and completed exams

📂 [`exam-schedule/`](./exam-schedule)

---

### 🍽️ Meal App

A Flutter application for browsing recipes and dishes using **TheMealDB API**.

**Features:**
- Browse meals by category
- View detailed recipe information
- Explore ingredients and preparation instructions
- Discover random meals
- Fetch recipe data from an external REST API

📂 [`meal-app/`](./meal-app)

## Technologies

- Flutter
- Dart
- REST APIs
- TheMealDB API
- Material Design
